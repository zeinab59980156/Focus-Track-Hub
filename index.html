# FocusTrack - برنامج التركيز العام # كاميرا فقط - لا تسجيل - تنبيه عند التشتت import cv2 import mediapipe as mp import numpy as np import time print("FocusTrack شغال - الكاميرا لا تسجل، تحليل لحظي فقط") print("دوس q للخروج") mp_face_mesh = mp.solutions.face_mesh face_mesh = mp_face_mesh.FaceMesh(max_num_faces=1, refine_landmarks=True) # نقاط العين LEFT_EYE = [362, 385, 387, 263, 373, 380] RIGHT_EYE = [33, 160, 158, 133, 153, 144] def get_ear(eye_points, landmarks, w, h): coords = [(int(landmarks[p].x * w), int(landmarks[p].y * h)) for p in eye_points] v1 = np.linalg.norm(np.array(coords[1]) - np.array(coords[5])) v2 = np.linalg.norm(np.array(coords[2]) - np.array(coords[4])) h1 = np.linalg.norm(np.array(coords[0]) - np.array(coords[3])) return (v1 + v2) / (2.0 * h1) cap = cv2.VideoCapture(0) last_alert = 0 while True: ret, frame = cap.read() if not ret: break h, w = frame.shape[:2] rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB) results = face_mesh.process(rgb) is_distracted = False if results.multi_face_landmarks: for lm in results.multi_face_landmarks: left_ear = get_ear(LEFT_EYE, lm.landmark, w, h) right_ear = get_ear(RIGHT_EYE, lm.landmark, w, h) avg_ear = (left_ear + right_ear) / 2.0 # لو العين مقفولة أو الرأس لافف nose_x = lm.landmark[1].x if avg_ear < 0.21 or abs(nose_x - 0.5) > 0.12: is_distracted = True else: is_distracted = True # مفيش وش = مشتت # لو حصل تشتت ادي انذار if is_distracted: # إنذار بصري وصوتي cv2.rectangle(frame, (0,0), (w,h), (0,0,255), 8) cv2.putText(frame, "ارجع ركز! - تشتت", (30, 60), cv2.FONT_HERSHEY_SIMPLEX, 1.1, (0,0,255), 3) # إنذار صوتي كل ثانيتين عشان ميزعجش if time.time() - last_alert > 2: print("\a") # صوت تنبيه last_alert = time.time() else: cv2.putText(frame, "مركز", (30, 60), cv2.FONT_HERSHEY_SIMPLEX, 1.1, (0,255,0), 3) cv2.putText(frame, "الكاميرا لا تسجل - تحليل لحظي فقط", (10, h-15), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (255,255,255), 1) cv2.imshow("FocusTrack - كاميرا التركيز", frame) if cv2.waitKey(1) & 0xFF == ord('q'): break cap.release() cv2.destroyAllWindows() print("تم الإغلاق - لم يتم حفظ أي صورة")
